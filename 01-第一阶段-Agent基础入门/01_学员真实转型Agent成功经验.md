## 总结

其实写 [Agent 全栈转型通关秘籍：企业级知识库项目 ](https://mp.weixin.qq.com/mp/appmsgalbum?__biz=MzYzNzI2MTI2Nw==&amp;action=getalbum&amp;album_id=4306749160512208899&amp;scene=126&amp;sessionid=#wechat_redirect)以来，我见证了好多同学从前端、测试、Java 后端转到了 Agent 全栈岗

总体来说我觉得现在这个 Agent 赛道找工作容易多了，比那些传统前后端。

而且大龄、gap 一两年的成功的也不少。

好多同学都是一周内 offer，这说明  Agent 项目经验还是很有竞争力的，在市面上还是稀缺

课程会提供一堆 Agent 真实简历，你可以参考来写自己的简历。

后面我会继续整理一些 Agent 面试题，提前准备一下。

然后多面几次，第一次可能没经验有的问题答不好，但第二次就好了

好几个同学都是第一次到二三面没答好，但是第二次面就很顺利了。

前几次不顺利没啥，慢慢积累面试经验，继续面就行。

总之，现在 Agent 全栈开发岗还在红利期，岗位多，有 Agent 全栈项目经验的少，从前端、后端、测试等转型到 Agent 全栈比较容易成功，大家要有信心，好好准备，多面一些，大概率是没问题的。
