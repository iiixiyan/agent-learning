# 43. 大模型训练、推理全流程详细图解

> 阶段：第四阶段 | 目标：理解大模型从训练到推理的完整生命周期

## 大模型生命周期全景

```
数据准备 → 预训练 → 监督微调(SFT) → 人类反馈强化学习(RLHF) → 部署推理 → 持续优化
   ↓           ↓            ↓                  ↓                  ↓           ↓
 清洗过滤    无监督学习    指令跟随        对齐人类价值观        API服务     数据回流
 去重去重    预测下一词    学习回答格式      更安全更有用         量化加速     模型迭代
```

## 第一阶段：数据准备

### 数据来源
- **网页数据**：CommonCrawl、维基百科、知乎、GitHub 代码
- **书籍文档**：电子书、技术文档、论文
- **对话数据**：客服对话、论坛问答

### 数据处理流程
```
原始数据 → 去重 → 过滤低质量 → 语言识别 → 敏感内容过滤 → 分词 → 训练语料
```

```python
# 数据清洗示例
import re
from collections import Counter

def clean_text(text):
    # 1. 去除 HTML 标签
    text = re.sub(r'<[^>]+>', '', text)
    # 2. 去除多余空白
    text = re.sub(r'\s+', ' ', text).strip()
    # 3. 过滤过短文本
    if len(text) < 50:
        return None
    return text

def deduplicate(texts):
    """基于 MinHash / SimHash 去重"""
    # 实际项目用 datasketch 库
    seen = set()
    unique = []
    for text in texts:
        # 简单去重：用前100字的hash
        key = hash(text[:100])
        if key not in seen:
            seen.add(key)
            unique.append(text)
    return unique
```

## 第二阶段：预训练（Pre-training）

### 目标
让模型学会语言规律和世界知识。**无监督学习**，预测下一个 token。

### 训练目标
```
输入: "我喜欢吃" → 模型预测下一个词 → "苹果"
损失函数: 交叉熵（CrossEntropy）
```

```python
import torch
import torch.nn.functional as F

# 简化的预训练步骤
def pretrain_step(model, batch, optimizer):
    input_ids = batch["input_ids"]  # (batch, seq_len)
    labels = batch["labels"]        # 与 input_ids 相同，但 shift 一位

    # 前向传播
    outputs = model(input_ids)
    logits = outputs.logits  # (batch, seq_len, vocab_size)

    # 计算损失（预测下一个 token）
    shift_logits = logits[:, :-1, :].contiguous()
    shift_labels = labels[:, 1:].contiguous()
    loss = F.cross_entropy(
        shift_logits.view(-1, shift_logits.size(-1)),
        shift_labels.view(-1),
        ignore_index=-100
    )

    # 反向传播
    optimizer.zero_grad()
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 梯度裁剪
    optimizer.step()

    return loss.item()
```

### 关键技术
- **混合精度训练**（FP16/BF16）：省显存、提速
- **梯度累积**：小 batch 模拟大 batch
- **梯度检查点**：用计算换显存
- **ZeRO 优化**：DeepSpeed 分布式训练
- **学习率调度**：Warmup + Cosine Decay

## 第三阶段：监督微调（SFT）

### 目标
让模型学会遵循指令、用指定格式回答。

### 数据格式
```json
[
  {"instruction": "写一首关于春天的诗", "input": "", "output": "春风拂面柳丝长..."},
  {"instruction": "解释什么是RAG", "input": "", "output": "RAG是检索增强生成..."}
]
```

```python
# SFT 训练（用 TRL 库）
from trl import SFTTrainer, SFTConfig
from datasets import Dataset

dataset = Dataset.from_json("sft_data.json")

config = SFTConfig(
    output_dir="./sft_model",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    learning_rate=2e-5,
    max_seq_length=2048,
)

trainer = SFTTrainer(
    model=base_model,
    args=config,
    train_dataset=dataset,
)
trainer.train()
```

## 第四阶段：RLHF（人类反馈强化学习）

### 目标
让模型输出更符合人类偏好、更安全、更有用。

### 三步流程
```
1. 训练奖励模型(RM)：人类对回答排序，训练模型打分
2. PPO 强化学习：用奖励模型指导模型优化
3. DPO（简化版）：直接用偏好数据优化，不需要奖励模型
```

```python
# DPO 训练（更简单的 RLHF 替代方案）
from trl import DPOTrainer, DPOConfig

dpo_config = DPOConfig(
    output_dir="./dpo_model",
    num_train_epochs=1,
    per_device_train_batch_size=2,
    learning_rate=5e-7,
    beta=0.1,  # DPO 的温度参数
)

trainer = DPOTrainer(
    model=sft_model,
    args=dpo_config,
    train_dataset=preference_dataset,  # 包含 chosen 和 rejected
)
trainer.train()
```

## 第五阶段：推理部署

### 推理优化技术

| 技术 | 原理 | 效果 |
|------|------|------|
| 量化（INT8/INT4） | 降低参数精度 | 显存减半，速度提升 |
| KV Cache | 缓存历史 K/V | 避免重复计算 |
| 连续批处理 | 动态合并请求 | 提升吞吐量 |
| Speculative Decoding | 小模型猜+大模型验 | 提速 2-3 倍 |
| PagedAttention | 分页管理 KV Cache | 显存利用率提升 |

```python
# vLLM 部署（生产级推理引擎）
from vllm import LLM, SamplingParams

llm = LLM(model="gpt2", tensor_parallel_size=1, gpu_memory_utilization=0.9)
sampling_params = SamplingParams(temperature=0.7, top_p=0.9, max_tokens=512)

outputs = llm.generate(["写一首关于秋天的诗"], sampling_params)
for output in outputs:
    print(output.outputs[0].text)
```

### API 服务
```python
# FastAPI 封装
from fastapi import FastAPI
from pydantic import BaseModel
import uvicorn

app = FastAPI()

class ChatRequest(BaseModel):
    message: str
    temperature: float = 0.7

@app.post("/chat")
async def chat(req: ChatRequest):
    outputs = llm.generate([req.message], SamplingParams(temperature=req.temperature, max_tokens=512))
    return {"response": outputs[0].outputs[0].text}

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## 学习要点

1. 大模型训练分四步：预训练→SFT→RLHF→部署，每步目标不同
2. 预训练是无监督学习，预测下一个 token，学会语言和知识
3. SFT 让模型学会遵循指令，数据质量比数量重要
4. RLHF/DPO 让模型对齐人类偏好，更安全更有用
5. 推理优化是生产关键，量化、KV Cache、vLLM 是必备技能
6. 作为应用开发者，重点理解推理和微调，预训练了解即可
