# 55. 企业级知识库项目：用户鉴权流程

> 阶段：第五阶段 | 前置知识：FastAPI、JWT、密码学基础

## 鉴权 vs 认证

- **认证（Authentication）**：你是谁？（验证身份，登录）
- **鉴权（Authorization）**：你能做什么？（验证权限，访问控制）

企业级知识库必须有完整的鉴权体系，防止未授权访问敏感文档。

## 整体流程

```
用户注册 → 密码加密存储 → 用户登录 → 签发 JWT Token → 后续请求带 Token → 验证 Token → 检查权限 → 允许/拒绝
```

# security.py
from passlib.context import CryptContext
import hashlib
import secrets

# 用 bcrypt 加密密码（自动加盐）
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(password: str) -> str:
    """加密密码"""
    return pwd_context.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    """验证密码"""
    return pwd_context.verify(plain_password, hashed_password)

# 生成 API Key（用于系统间调用）
def generate_api_key() -> str:
    return "sk-" + secrets.token_hex(24)

### 2. JWT Token 管理

```python
# jwt_utils.py
from datetime import datetime, timedelta
from jose import JWTError, jwt
from typing import Optional

SECRET_KEY = "your-secret-key-change-in-production-use-env"
ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_MINUTES = 30  # 访问令牌 30 分钟
REFRESH_TOKEN_EXPIRE_DAYS = 7      # 刷新令牌 7 天

def create_access_token(data: dict, expires_delta: Optional[timedelta] = None):
    """创建访问令牌"""
    to_encode = data.copy()
    expire = datetime.utcnow() + (expires_delta or timedelta(minutes=ACCESS_TOKEN_EXPIRE_MINUTES))
    to_encode.update({"exp": expire, "type": "access"})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

def create_refresh_token(data: dict):
    """创建刷新令牌"""
    to_encode = data.copy()
    expire = datetime.utcnow() + timedelta(days=REFRESH_TOKEN_EXPIRE_DAYS)
    to_encode.update({"exp": expire, "type": "refresh"})
    return jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)

def decode_token(token: str) -> Optional[dict]:
    """解码并验证 Token"""
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        return payload
    except JWTError:
        return None
```

@app.post("/auth/refresh", response_model=TokenResponse)
async def refresh_token(refresh_token: str):
    payload = decode_token(refresh_token)

### 4. 文档级权限控制

```python
# document_permissions.py
from fastapi import Depends, HTTPException
from auth import get_current_user, UserInfo

# 文档权限模型
class DocumentPermission:
    def __init__(self):
        # 实际项目存在数据库
        self.permissions = {}  # {doc_id: {"owner": user_id, "shared_with": [user_ids], "is_public": bool}}

    def can_read(self, user_id: int, doc_id: int) -> bool:
        perm = self.permissions.get(doc_id)
        if not perm:
            return False
        return (perm["is_public"] or
                perm["owner"] == user_id or
                user_id in perm["shared_with"])

    def can_write(self, user_id: int, doc_id: int) -> bool:
        perm = self.permissions.get(doc_id)
        return perm and perm["owner"] == user_id

doc_perms = DocumentPermission()

# 权限检查依赖
def require_doc_read(doc_id: int):
    async def checker(current_user: UserInfo = Depends(get_current_user)):
        if not doc_perms.can_read(current_user.id, doc_id):
            raise HTTPException(403, "无权访问该文档")
        return current_user
    return checker

# 使用
@app.get("/documents/{doc_id}/content")
async def get_document_content(
    doc_id: int,
    current_user: UserInfo = Depends(require_doc_read(doc_id))
):
    return {"doc_id": doc_id, "content": "文档内容..."}
```

## 安全最佳实践

### 1. 密码安全
- 用 bcrypt/argon2 加密，不要用 MD5/SHA1
- 密码强度校验（最少8位，含大小写+数字）
- 登录失败次数限制（防暴力破解）

### 2. Token 安全
- Access Token 短期（15-30分钟），Refresh Token 长期（7天）
- 生产环境用 HTTPS 传输
- Token 存在 HttpOnly Cookie 比 localStorage 更安全（防 XSS）
- 支持 Token 黑名单（用户登出/改密后旧 Token 失效）

### 3. 接口安全
- 所有接口默认需要登录，公开接口显式标注
- 管理员接口单独校验角色
- 文档级权限细粒度控制（所有者/共享/公开）
- 接口限流（防刷）

### 4. 其他
- 敏感操作（删除文档、修改权限）需要二次确认
- 记录操作日志（谁在什么时候做了什么）
- 定期审计权限配置

## 学习要点

1. 认证（你是谁）和鉴权（你能做什么）是两个不同概念
2. 密码用 bcrypt 加密，不要明文存储
3. JWT 分 Access Token（短期）和 Refresh Token（长期），提升安全性
4. FastAPI 用 Depends 实现依赖注入，鉴权逻辑复用方便
5. 企业级系统需要文档级权限控制，不是登录了就能看所有文档
6. 生产环境一定要 HTTPS + Token 黑名单 + 操作日志
