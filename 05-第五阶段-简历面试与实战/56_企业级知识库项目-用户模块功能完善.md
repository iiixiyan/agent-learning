## 用户模块功能清单

一个完整的用户模块包含：

```
用户模块
├── 账户管理
│   ├── 注册（邮箱/手机号/第三方登录）
│   ├── 登录（密码/验证码/SSO）
│   ├── 登出
│   ├── 修改密码
│   ├── 忘记密码（邮箱/短信重置）
│   └── 账户注销
├── 个人信息
│   ├── 查看/修改个人资料
│   ├── 上传头像
│   ├── 绑定/换绑邮箱手机
│   └── 偏好设置（语言、主题、通知）
├── 权限管理
│   ├── 角色管理（admin/editor/viewer）
│   ├── 权限分配
│   └── 操作日志
└── 安全设置
    ├── 登录设备管理
    ├── 两步验证（2FA）
    ├── 登录历史
    └── API Key 管理
```

## 学习要点

1. 用户模块不只是登录注册，还包括资料管理、密码管理、安全设置、权限管理
2. 密码修改后要使旧 Token 失效（Token 黑名单机制）
3. 忘记密码用邮件/短信重置，Token 有效期短（1小时），防枚举攻击
4. API Key 只在创建时显示完整值，之后只显示前缀，存储用 hash
5. 操作日志是企业级系统必备，记录谁在什么时候做了什么
6. 登录设备管理让用户可以远程登出被盗设备
7. 两步验证（2FA）是高安全等级系统的标配（TOTP/短信/邮箱）
